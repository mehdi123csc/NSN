NSN 3D Store — prototype

Included:
- index.html: Arabic RTL storefront with a Three.js 3D mall scene, animated stylized runway model, interactive camera drag, product categories, search, favorites, and demo cart.
- Three.js is loaded from jsDelivr CDN, so internet access is needed for the 3D scene.

Important:
- This is a front-end prototype. Demo products/cart are stored only in the browser memory.
- It is NOT yet connected to your Supabase project, real inventory, admin dashboard, order submission, payments, shipping, or authentication.
- Before replacing your current QMR site, keep a backup and test this as a separate GitHub repository or branch.
- To publish on GitHub Pages: upload index.html to a repository, enable Settings > Pages, and open the generated Pages address.
